# Talking to the detector

Covers `source.py`, `api.py`, `birdweather.py`, `taxa.py`, `languages.py` and `fake.py` - everything that reaches the detector, a BirdNET-Go or public BirdWeather stations (`Settings.detector_kind`). Anything asking "which detector" keys on `detector_address`, never `detector_url`, which stays set while a station is read.

**The API is the interface.** The halves meet at the detector's API - BirdNET-Go's `/api/v2` or BirdWeather's GraphQL - never at its database. A frame can therefore point at the container beside it, at a BirdNET-Go already running on the same machine, or at one across the house - all the same code path, only a different URL.

- `source.py` is the surface everything above sees. `api.py` and `birdweather.py` implement it, and are the only code that knows their upstream's endpoints.
- **A transport failure raises `Unavailable`; an empty list means the detector answered and there were no birds.** Never collapse the two. HTTP failures are routine, and a source that returned `[]` on a timeout would push a bare perch to the glass on the first blip. The render loop holds its last good page and the server holds the last one it served - dropped when the settings name another detector, since another station's birds are not ours. With nothing held the route answers 503; the admin still renders and says so.
- **One bird, one name.** Both detectors can serve a reclassified bird under its legacy and its current name as two species. Each source folds the pair under `names.canonical`, so nothing above it ever sees two; BirdWeather gives each name its own species id, and detections are asked for by id. Get this wrong and the species count and life list double, the newest arrival is dated to the day the name changed, and the bird lands on the sheet twice.
- **Only birds come off the source** (`taxa.py`). A detector classifies more than birds - a BirdNET-Go can run a bat or multi-taxa model beside the one that hears them, and BirdWeather hears bats, insects and noise too - so every source drops what `is_bird` rejects, and BirdWeather's what it does not class `avian`, since only its detections take that filter. Two halves, neither a judgement call about a species: v2.4's own label set is an allowlist, which is what catches a bat whatever its genus, since a name that model never emitted has no artwork by construction (`tests/test_artwork_names.py` pins the filenames to those labels, under their current spelling); and `NON_BIRD_GENERA` covers the 101 labels inside v2.4 that are noise classes, frogs, crickets, squirrels and other mammals, read off eBird's own `t-` species codes rather than judged one by one. Every drop is logged once per species, since a bird that silently stops appearing is otherwise unaccountable. An unreadable label file fails open, allowlist off and genus check standing: the odd frog on the glass beats a blank one.
- Both halves key through `names.normalize` and each source filters after folding its pairs, so a species reclassified since v2.4 answers to the label's spelling and to the detector's alike. Match raw text instead and the goshawk goes the way of a bat.
- `api.Configured` wraps the source and rebuilds it when the settings name a different detector, so one save reaches the loop, the server and `languages` at once. It must never call out to another module while holding its lock.
- `fake.py` serves the same endpoints over generated detections, so the dev loop, the tests and `fugleramme-check` all run without a container or a network. It is also where upstream's real response shapes are written down, and its station hears a bat, a squirrel and a noise class among the birds so the filter is exercised everywhere it is used. `--every-language` also serves a dictionary for each locale in its `LABELS`, which upstream has none for, so every script is its own Language entry instead of one station language at a time. `--birdweather` serves BirdWeather instead: two stations in two zones (`fake.STATIONS`), its goshawk under both names.

## BirdNET-Go (`api.py`)

- **The endpoints disagree about which bird is which.** BirdNET-Go rewrites a scientific name to its current form as it stores a detection but leaves rows it already stored alone, so a station upgraded across a reclassification serves one bird as two species forever - and BirdNET's own labels keep the old name regardless. `api._merged` folds the summary's two rows into one and `_detection` canonicalizes the feed.
- The endpoints disagree about time: the species summary filters on whole dates, so a window shorter than a day is counted off the feed instead. Each stamp carries the station's offset at that instant, so a feed row is read off its own `timestamp`, never one offset for all: across a daylight-saving change the older rows would land an hour out. BirdNET-Go stamped the feed bare before 20260321 and the summary before 20260712; `_aware` reads such a stamp in the frame's zone, with one warning per station.
- **A slow station is still a station.** The all-time summary, which the life list asks on every tick, can take many seconds on a large database such as one migrated from BirdNET-Pi. So `_cached` holds an answer `_HOLD` times as long as it took, never under `_TTL`, which leaves a fast station as it was; `probe` asks `/detections/recent` for one row instead of the summary; and the timeout is 30s (`FUGLERAMME_DETECTOR_TIMEOUT`).

## BirdWeather (`birdweather.py`)

- A station BirdWeather does not have answers 404 with an HTML page (`NoSuchStation`, "no such station" everywhere, never "unreachable"), and a GraphQL error answers 200 with `errors`.
- **Several stations are one.** The root fields take them all as `stationIds`, so a species heard at more than one is one bird, and the stations must share a site (`source.station_fault`). `stationIds` skips a station BirdWeather does not have, but `station(id)` answers 404 for one and fails the whole query, so `about` asks each on its own and `_heard` leaves a missing one out: the rest still make a page, and with none left it is `NoSuchStation`, never no birds. A `detector_station` saved before several were read is a list of one.
- Root `detections` answers the last 24 hours unless given a `period`, so the feed asks for the whole record. Without it a station quiet since yesterday reads as empty.
- **Caching is ours.** A POST gets no working ETag, rate limits are undocumented, and many frames polling every few seconds can share one public station, so every answer is held; the record's last two UTC days are asked again each minute, since an upload can land on yesterday after UTC midnight.
- Limits it never reports: `first` caps at 500, `topSpecies` at 10 rows without a `limit`, and a query with more than three `detections` fields is refused. `detections.totalCount` counts every station's, so nothing reads it.
- **The station search** (`nearest`): `stations(ne, sw)` filters loosely by a box, so the circle is cut here. Each of `RADII_KM` is its own query, since one wide box can hit the 500 cap and miss the nearest. Without a `period` it answers every station ever set up.
- **`dailyDetectionCounts` bins by UTC day** whatever timezone is asked for, so the record starts at `earliestDetectionAt`'s UTC date.
- **There is no first-heard field.** The life list dates a species to its first UTC day, at noon so the date holds from UTC-11 to UTC+12. Only a first day of today or yesterday is read to the detection, since "new" is counted in hours (`modes.NEW_HOURS`) and detections come newest first only, so that reads the whole day.

## The detector owns the names (`languages.py`)

- The frame keys everything on the scientific name and asks the detector for the rest, through the same source as the detections.
- `GET /api/v2/settings/locales` lists locales, `HEAD /api/v2/species/dictionary/<code>` says which have one. The two disagree on codes (the list's `no` answers as `nb`), so a language's code is its dictionary's.
- Dictionaries cache in `detector/data/names/`, revalidated by ETag, and carry the station they came from so re-pointing the frame cannot serve another station's names. With nothing cached and nothing answering, the only language is `sci`.
- **The names are gated where the detections are not.** BirdNET-Go registers `/settings/*` behind its auth middleware whenever any provider is configured, while the detections only answer to `PrivateMode` - so a station happily serving birds to a frame with no password still refuses it the locale list, and the language menu collapses to the scientific name. `catalog_failure` carries the reason to the admin, `api.probe` tests both endpoints, and `fake.serve(private=False)` is that shape. The Detector row says `needs a password` beside `running` for it - red when PrivateMode gates everything, amber when only the names are short. `/health` is not on upstream's PrivateMode exempt list and `hostinfo` asks it without credentials, so its 401 says the detector wants a password, never that this frame lacks one - only whether the page's own calls came back tells those apart. Where the admin would have put a bird it says the same in red, linked to that field (the `fix` macro), rather than "unreachable" - which would send the reader to an address that is answering fine.
- **An empty probe is a failure, not an answer.** Caching one would hold the menu empty for `_CATALOG_TTL` and write itself over the good list on disk, which no one can fix without a restart. The catalog is keyed on `ApiSource.station`, one per source, so entering the password the locale list was waiting for expires it at once - `Configured` builds a new source for a credential change as much as for an address.
- BirdNET-Go prompts for a password alone, but its login rejects an empty username and matches the one it is given against `security.basicauth.clientid`. The admin asks for no username; the frame sends `api.CLIENT_ID`, that setting's default. `Settings.detector_username` stays for an install that changed the id.
- **`station` is whatever BirdNET-Go's species language is set to** (`birdnet.locale`), read from `/species/all`. It is the only way to the label locales the 16 dictionaries miss. `/settings/birdnet` names that language, for the label and the dates, and is gated like `/settings/locales`: without the password the names still arrive, under a bare label with numeric dates. `/species/all` sends no ETag, so the version hashes the body and the locale, and `_STATION_TTL` is short so a change in BirdNET-Go reaches the page within minutes. It is offered once `/settings/locales` gets any answer, 401 included, and stays offered: `languages.json` keeps that beside `birdnet.locale`, which names it until the station names' fresher copy loads. An empty locale is a refusal, never a replacement. It is offered beside a dictionary of the same language, never merged with it: the dictionary is fixed, `station` follows BirdNET-Go. Its names can be in any script; one this Pi has no face for falls back to the scientific name ([render.md](render.md)).
- Norwegian names arrive lowercase and English titled, so a label capitalizes the first letter only.
- **A BirdWeather station names its own birds** (`BirdWeatherSource.common_names`), with no `station` language. It has no `en` translation, so English is each species' `commonName`; its locales map to the frame's codes (`no` to `nb`, `in` to `id`, `zh-SM` to `zh`), and regional ones such as `pt-BR` stay their own entries. Some are thin (`hi` named 3 of one station's 23 species), so a missing name falls back to the scientific one. `zh-SM` is not purely Simplified and a legacy row's can be Traditional, so a legacy row only fills what the current one lacks.
- A plate's date follows the primary language too, via `babel`: `Namer.date` for the newest arrival (a day and its year, which can be months back), `Namer.moment` for the latest bird (a day and a clock time). Languages differ in more than the month's name - Hungarian and Latvian put the year first, only some join the day and time with a comma - so a hand-rolled table would get them wrong. `sci`, and any language `babel` lacks, get a numeric date.
- The plates carry no words beyond the name. Nothing translates UI text, so "First heard" became the year. Narrow no-break spaces are flattened to plain ones: CLDR asks for one before AM/PM and five of the seven label faces draw a box instead of it.
